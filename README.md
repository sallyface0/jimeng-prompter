# 即梦 Prompt 大师 — AI 视频结构化提示词引擎

> 面向即梦 Seedance 2.0 / 抖音创作者的提示词专家。不会写 AI 视频提示词？你来创意，我来翻译成即梦能懂的语言。
> v1.1 新增：交互式风格菜单、失败降级修复、成片自查清单。

## ✨ 核心理念

普通用户做 AI 视频最大的痛点不是"没创意"，而是**创意翻译不成即梦能用的提示词**——写太短画面崩，写太长 AI 懵。

即梦 Prompt 大师用**双角色协作**解决这个问题：

| 角色 | 职责 |
|---|---|
| 🎬 **Director** | 渐进式挖掘需求，一次只问一个问题，最多 5 轮锁定创意方向 |
| 🛠️ **Prompt Crafter** | 把锁定方案拆成即梦能直接粘贴的分镜表 + 反向词 + 概念图提示词 |

**导演不写词，匠人不改设计。** 分工明确，各司其职。

### 三阶段流水线

```
你的创意
    ↓
Phase 1: Director 渐进式需求挖掘（一次一问，最多5轮）
    ↓
Phase 2: Director 方案预演 + 强制等待确认
    ↓
Phase 3: Prompt Crafter 生产级输出
    ├── 全局反向提示词（粘贴到即梦 Negative Prompt）
    ├── 全局风格锁（每段开头强制粘贴，画风不跳）
    ├── 分镜制作表（即梦正向提示词 + 台词/旁白 + BGM/音效）
    ├── 3 张概念图提示词（定妆 / 全景 / 封面）
    └── 即梦实操步骤指引
```

### 8 大避坑规范

| 陷阱 | 规避 |
|---|---|
| 人物崩坏 | 画面 ≤2 人 + `anatomically correct hands` |
| 画风突变 | 全局风格锁每镜强制粘贴 |
| 多人错乱 | ≥3 人用远景 |
| 动作鬼畜 | 用静态瞬间代替动态动词 |
| 文字乱码 | 不生成画面文字，后期剪映加 |
| 面部崩坏 | 近景加 `symmetrical face` |
| 夜景噪点 | 加 `well-lit night scene` |
| 角色不一致 | 风格锁含主角固定特征 |
